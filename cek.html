Cek koneksi backend

Halaman ini untuk admin: memeriksa apakah website bisa membaca data dari Google Apps Script.

Bila gagal (404 / tidak terhubung)

  1. Di editor Apps Script: Terapkan › Kelola deployment. Pastikan ada deployment Aplikasi web yang aktif (bukan diarsipkan).
  2. Klik ikon pensil: Jalankan sebagai: Saya dan Yang memiliki akses: Siapa saja (bukan "Siapa saja yang memiliki Akun Google"). Pilih Versi: Versi baru › Terapkan.
  3. Salin URL Aplikasi web (berakhiran /exec) ke assets/js/config.js › API_URL.
  4. Pesan "Sistem belum terpasang": di editor Apps Script, pilih fungsi perbaruiSistem lalu Jalankan.
  5. Bila memakai akun Google Workspace (domain lembaga), admin domain bisa melarang akses "Siapa saja". Pakai akun Gmail pribadi untuk Apps Script.
